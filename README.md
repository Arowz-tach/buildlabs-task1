\# BuildLabs DevOps Task Manager



A simple Flask-based task management API created as part of the BuildLabs DevOps Internship Task 1.



The project demonstrates basic application development, Git version control, GitHub collaboration, and containerization with Docker.



\## Features



\- Flask-based REST API

\- Health check endpoint

\- Task listing endpoint

\- JSON responses

\- Docker containerization

\- Environment variable support
